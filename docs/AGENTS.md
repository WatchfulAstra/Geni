# Savi Browser Agent — Agent Guide

## What You Have Access To

You have access to a browser through the Savi Browser Agent MCP server.

The browser is a real Chromium browser controlled through Playwright.

You can:

1. Open websites.
2. Read webpages.
3. Click elements.
4. Enter text.
5. Wait for pages to update.
6. Take screenshots as visual evidence.
